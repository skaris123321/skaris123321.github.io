# 📦 Инструкция по запуску сервера заказов РОСЭК

## Что это?

Это backend сервер, который:
- ✅ Принимает заказы с вашего сайта
- ✅ Автоматически отправляет красивые письма на почту
- ✅ Сохраняет все заказы в файлы
- ✅ Отправляет подтверждение клиенту

## Быстрый старт (5 минут)

### Шаг 1: Установите Node.js

1. Скачайте с https://nodejs.org/
2. Выберите версию "LTS" (рекомендуемая)
3. Установите с настройками по умолчанию
4. Перезагрузите компьютер

### Шаг 2: Получите пароль приложения Gmail

Чтобы сервер мог отправлять письма через Gmail:

1. Откройте https://myaccount.google.com/security
2. Найдите "Двухэтапная аутентификация" и включите её
3. Вернитесь на страницу безопасности
4. Найдите "Пароли приложений" (App Passwords)
5. Выберите:
   - Приложение: "Почта"
   - Устройство: "Другое" → введите "ROSEK Server"
6. Нажмите "Создать"
7. **СКОПИРУЙТЕ** сгенерированный пароль (16 символов без пробелов)

### Шаг 3: Настройте файл .env

1. Откройте файл `server/.env` в блокноте
2. Найдите строку `EMAIL_PASS=your-app-password-here`
3. Замените `your-app-password-here` на скопированный пароль
4. Сохраните файл

Должно получиться примерно так:
```
EMAIL_PASS=abcdеfghijklmnop
```

### Шаг 4: Запустите сервер

1. Откройте папку `server`
2. Дважды кликните на файл `START.bat`
3. Подождите пока установятся зависимости
4. Увидите сообщение "🚀 РОСЭК Order Server запущен"

**ВАЖНО:** Не закрывайте это окно! Сервер должен работать постоянно.

### Шаг 5: Проверьте работу

1. Откройте браузер
2. Перейдите на http://localhost:3000/api/health
3. Должны увидеть: `{"status":"ok","message":"Сервер работает"}`

Готово! Теперь заказы с сайта будут автоматически отправляться на почту.

## Как это работает?

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│   Клиент    │         │   Сервер    │         │    Gmail    │
│  (браузер)  │────────▶│  Node.js    │────────▶│   (почта)   │
└─────────────┘         └─────────────┘         └─────────────┘
  Заполняет форму       Обрабатывает           Отправляет письмо
  Нажимает "Отправить"  Сохраняет заказ        менеджеру и клиенту
```

1. Клиент заполняет форму на сайте
2. Браузер отправляет данные на сервер (localhost:3000)
3. Сервер:
   - Сохраняет заказ в папку `orders/`
   - Отправляет красивое HTML письмо вам
   - Отправляет подтверждение клиенту
4. Вы получаете письмо с деталями заказа

## Где хранятся заказы?

Все заказы сохраняются в папке `server/orders/`

Каждый заказ - это отдельный JSON файл с названием:
```
order-2026-02-23T15-30-45.json
```

Можно открыть в блокноте и посмотреть все детали.

## Что делать если не работает?

### Ошибка: "Node.js не установлен"
- Установите Node.js с https://nodejs.org/
- Перезагрузите компьютер

### Ошибка: "Ошибка подключения к email"
- Проверьте пароль приложения в файле `.env`
- Убедитесь что включена двухфакторная аутентификация в Google
- Попробуйте создать новый пароль приложения

### Ошибка: "Port 3000 already in use"
- Порт 3000 уже занят другой программой
- Откройте `.env` и измените `PORT=3000` на `PORT=3001`
- В файле `category/cart.html` измените `localhost:3000` на `localhost:3001`

### Заказы не приходят на почту
- Проверьте папку "Спам" в Gmail
- Убедитесь что сервер запущен (окно START.bat открыто)
- Посмотрите логи в окне сервера - там будут ошибки

## Для продакшена (реальный сайт)

Сейчас сервер работает только на вашем компьютере (localhost).

Для реального сайта нужно:
1. Арендовать VPS сервер (Timeweb, Beget, DigitalOcean)
2. Загрузить туда код сервера
3. Настроить домен и HTTPS
4. Изменить в `cart.html` адрес с `localhost:3000` на `https://ваш-домен.ru`

Могу помочь с настройкой когда будете готовы!

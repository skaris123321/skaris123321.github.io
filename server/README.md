# РОСЭК Order Server

Backend сервер для обработки заказов с сайта РОСЭК.

## Что делает сервер:

1. ✅ Принимает данные заказа с сайта
2. ✅ Сохраняет заказы в папку `orders/` (JSON файлы)
3. ✅ Отправляет красивое HTML письмо на почту менеджера
4. ✅ Отправляет подтверждение клиенту на его email
5. ✅ Логирует все действия в консоль

## Установка и запуск:

### 1. Установите Node.js
Скачайте и установите с https://nodejs.org/ (версия 18 или выше)

### 2. Установите зависимости
```bash
cd server
npm install
```

### 3. Настройте Gmail для отправки писем

Для отправки писем через Gmail нужно создать "Пароль приложения":

1. Откройте https://myaccount.google.com/security
2. Включите двухфакторную аутентификацию (если еще не включена)
3. Перейдите в "Пароли приложений" (App Passwords)
4. Выберите "Почта" и "Другое устройство"
5. Введите название: "ROSEK Order Server"
6. Скопируйте сгенерированный пароль (16 символов)

### 4. Настройте файл .env

Откройте файл `server/.env` и вставьте пароль приложения:

```env
PORT=3000
EMAIL_USER=enogovicina167@gmail.com
EMAIL_PASS=ваш-пароль-приложения-здесь
ORDER_EMAIL=enogovicina167@gmail.com
```

### 5. Запустите сервер

```bash
npm start
```

Или для разработки с автоперезагрузкой:
```bash
npm run dev
```

Сервер запустится на http://localhost:3000

## Проверка работы:

Откройте в браузере: http://localhost:3000/api/health

Должны увидеть:
```json
{
  "status": "ok",
  "message": "Сервер работает",
  "timestamp": "2026-02-23T..."
}
```

```
├── .env.example      # Пример настроек

│   └── order-2026-02-23T15-30-00.json
└── README.md         # Эта инструкция
```

## Как работает:

1. Клиент заполняет форму на сайте и нажимает "Отправить заказ"
2. Браузер отправляет POST запрос на `http://localhost:3000/api/orders`
3. Сервер получает данные и:
   - Сохраняет заказ в JSON файл
   - Отправляет красивое HTML письмо менеджеру
   - Отправляет подтверждение клиенту
4. Возвращает ответ браузеру (успех/ошибка)

## Логи:

Сервер выводит в консоль:
- ✅ Успешные операции (зеленые галочки)
- ❌ Ошибки (красные крестики)
- 📦 Информацию о заказах
- 📧 Статус отправки email

# Автоматическая интеграция интернет-магазина с 1С

Данная инструкция описывает настройку полностью автоматической интеграции сайта с 1С:Предприятие для автоматической обработки заказов, обновления цен и синхронизации остатков товаров.

## Требования для автоматической работы

Для автоматической интеграции обязательно требуется серверная версия 1С:Предприятие с поддержкой HTTP-сервисов. Файловая версия 1С не поддерживает автоматическую интеграцию с интернет-сайтами.

## Настройка сайта

### Конфигурация подключения к 1С

Откройте файл `config.ini` и настройте параметры подключения:

```ini
; Токен для защиты API обновления цен
API_TOKEN = "ваш-секретный-токен-123"

; Параметры подключения к серверу 1С
ONEC_API_URL = "http://ваш-сервер-1с:8080/база/hs/orders/create"
ONEC_USERNAME = "WebService"
ONEC_PASSWORD = "пароль-пользователя-1с"
ONEC_RETRY_ATTEMPTS = 3
```

### Настройка QR-кода для оплаты

Получите QR-код от банка и сохраните его как `images/qr-payment.png` для автоматического отображения реквизитов оплаты.

## Принципы автоматической работы

### Обработка заказов
Клиент оформляет заказ на сайте → заказ автоматически передается в 1С через HTTP API → в 1С создается документ "Заказ покупателя" → клиент получает автоматическое подтверждение

### Обновление цен
Регламентное задание в 1С (каждый час) → автоматическая выгрузка актуальных цен → обновление цен на сайте через защищенный API → покупатели видят актуальную информацию

### Контроль остатков
1С отслеживает остатки на складах → при изменении остатков автоматически обновляется информация на сайте → товары без остатков помечаются "Под заказ"

## Преимущества автоматизации

Автоматическая интеграция обеспечивает:
- Работу интернет-магазина 24/7 без участия персонала
- Актуальные цены и остатки в реальном времени
- Автоматическую обработку заказов без ручного ввода
- Исключение ошибок при передаче данных
- Экономию времени менеджеров
- Увеличение конверсии сайта

## Вопросы для хостинг-провайдера

Здравствуйте! Хочу разместить интернет-магазин с автоматической интеграцией 1С. Подскажите по ключевым требованиям:

### Технические требования

1. Поддерживается ли PHP версии 7.4 или новее?
Сайт написан на PHP. Если версия старая, сайт не запустится и будут ошибки.

2. Можно ли отправлять HTTP-запросы на внешние серверы?
Сайт должен автоматически передавать каждый заказ в 1С по интернету. Если хостинг блокирует такие запросы, автоматизация работать не будет.

3. Есть ли бесплатный SSL-сертификат?
Без SSL браузеры показывают "Соединение не защищено", что отпугивает покупателей.

4. Можно ли отправлять email с сайта?
Клиенты должны получать подтверждения заказов на почту. Если хостинг не поддерживает отправку писем, клиенты не будут знать что заказ принят.

### Ресурсы и надежность

5. Сколько места на диске и какие ограничения на трафик?
Сайт с документами займет около 500 МБ. При активной работе нужно 15-20 ГБ трафика в месяц.

6. Какой процент времени работы гарантируется?
Интернет-магазин должен работать круглосуточно. Каждый час простоя это потерянные заказы.

7. Есть ли автоматическое резервное копирование?
В случае сбоя нужно быстро восстановить сайт, иначе остановка бизнеса.

### Домен и поддомены

8. Есть ли у вас возможность работать с доменами?
Нужно разместить сайт на поддомене существующего домена компании. Например, если домен компании rosek.ru, то сайт должен быть на shop.rosek.ru или store.rosek.ru.

9. Можно ли создавать неограниченное количество поддоменов?
В будущем может потребоваться создать несколько поддоменов для разных проектов или тестирования.

10. Как настраивается DNS для поддомена?
Нужно понимать процесс: нужно ли менять DNS записи у регистратора домена или все делается в панели управления хостингом.

### Поддержка и стоимость

11. Какая техническая поддержка?
Если сайт сломается в выходные, клиенты не смогут заказывать до понедельника. Нужна поддержка в любое время.

12. Сколько стоит подходящий тариф и есть ли скидки за год?

Сайт будет принимать заказы 24/7 и автоматически передавать их в 1С. Главное - стабильная работа без сбоев.

# Автоматическая интеграция интернет-магазина с 1С

Данная инструкция описывает настройку полностью автоматической интеграции сайта с 1С:Предприятие для автоматической обработки заказов, обновления цен и синхронизации остатков товаров.

## Требования для автоматической работы

Для автоматической интеграции обязательно требуется серверная версия 1С:Предприятие с поддержкой HTTP-сервисов. Файловая версия 1С не поддерживает автоматическую интеграцию с интернет-сайтами.

## Как работает процесс оформления заказа

### Шаг 1: Клиент заполняет данные и нажимает "Оплатить"

1. Клиент выбирает товары в каталоге
2. Добавляет их в корзину
3. Переходит в корзину и нажимает "Оформить заказ"
4. Заполняет форму с данными:
   - Название компании
   - ФИО контактного лица
   - Телефон
   - Email
   - Адрес доставки
5. Нажимает кнопку "Оплатить"

### Шаг 2: Заказ автоматически создается в 1С

Когда клиент нажимает "Оплатить":
1. Сайт отправляет данные заказа в 1С через HTTP API
2. В 1С автоматически создается документ "Заказ покупателя" со статусом "Ожидает оплаты"
3. Заказ содержит:
   - Данные клиента (компания, контактное лицо, телефон, email)
   - Список товаров с количеством и ценой
   - Сумму заказа
   - Дату и время создания

### Шаг 3: Клиент видит QR-код для оплаты

После создания заказа в 1С:
1. На экране клиента появляется страница с QR-кодом
2. QR-код содержит реквизиты для оплаты:
   - Номер счета компании
   - Сумму платежа
   - Назначение платежа (номер заказа)
3. Клиент может оплатить через:
   - Мобильное приложение банка (сканирует QR)
   - Интернет-банк (вводит реквизиты вручную)
   - Платежный терминал

### Шаг 4: Бухгалтерия проверяет оплату и запускает заказ в работу

После того как клиент оплатил:
1. Деньги приходят на счет компании
2. Бухгалтер видит платеж в банке
3. Бухгалтер открывает 1С и ищет соответствующий заказ:
   - По сумме платежа
   - По назначению платежа (номер заказа)
   - По дате
4. Когда находит заказ, проверяет что сумма совпадает
5. Меняет статус заказа в 1С с "Ожидает оплаты" на "Оплачено"
6. Запускает заказ в работу (передает в производство/склад)

## Настройка сайта

### Конфигурация подключения к 1С

Откройте файл `config.ini` и настройте параметры подключения:

```ini
; Токен для защиты API обновления цен
API_TOKEN = "ваш-секретный-токен-123"

; Параметры подключения к серверу 1С
ONEC_API_URL = "http://ваш-сервер-1с:8080/база/hs/orders/create"
ONEC_USERNAME = "WebService"
ONEC_PASSWORD = "пароль-пользователя-1с"
ONEC_RETRY_ATTEMPTS = 3
```

### Настройка QR-кода для оплаты

1. Получите реквизиты компании для оплаты:
   - Номер счета
   - БИК банка
   - Назначение платежа (шаблон)

2. Сгенерируйте QR-код через сервис:
   - https://qr-code.ru/ (российский сервис)
   - Или через приложение вашего банка

3. Сохраните QR-код как `images/qr-payment.png`

4. QR-код будет автоматически показываться на странице оплаты после создания заказа

## Принципы автоматической работы

### Обработка заказов
Клиент заполняет форму и нажимает "Оплатить" → сайт отправляет данные в 1С → в 1С создается документ "Заказ покупателя" со статусом "Ожидает оплаты" → клиент видит QR-код для оплаты → бухгалтер проверяет платеж и меняет статус на "Оплачено" → заказ запускается в работу

### Обновление цен
Регламентное задание в 1С (каждый час) → автоматическая выгрузка актуальных цен → обновление цен на сайте через защищенный API → покупатели видят актуальную информацию

### Контроль остатков
1С отслеживает остатки на складах → при изменении остатков автоматически обновляется информация на сайте → товары без остатков помечаются "Под заказ"

## Инструкция для программиста 1С

### Что нужно сделать

Программист 1С должен настроить автоматический прием заказов с сайта и автоматическую выгрузку цен на сайт.

### Требования

Обязательно нужна серверная версия 1С:Предприятие с поддержкой HTTP-сервисов. Файловая версия не работает.

### Шаг 1: Проверка версии 1С

1. Откройте 1С
2. Зайдите в "Справка" → "О программе"
3. Должно быть написано "1С:Предприятие 8.3 (сервер)" или подобное
4. Если файловая версия - нужно переходить на серверную

### Шаг 2: Создание HTTP-сервиса для приема заказов

1. Откройте Конфигуратор 1С
2. Перейдите в "Общие" → "Web-сервисы" → "HTTP-сервисы"
3. Создайте новый HTTP-сервис с именем `orders`
4. Добавьте URL-шаблон `create` с методом POST
5. В обработчике метода напишите код для создания заказа покупателя

Заказ будет приходить в формате JSON:
```json
{
  "client": {
    "name": "ООО Стройка",
    "phone": "+7 (495) 123-45-67",
    "email": "zakaz@stroyka.ru"
  },
  "items": [
    {
      "article": "AVR-100A",
      "name": "АВР 100А на 2 ввода",
      "quantity": 2,
      "price": 45000
    }
  ],
  "total": 90000
}
```

Нужно создать документ "Заказ покупателя" со статусом "Ожидает оплаты".

### Шаг 3: Создание пользователя для веб-сервиса

1. В 1С создайте пользователя `WebService`
2. Установите пароль (запишите его - понадобится для сайта)
3. Назначьте права:
   - Создание документов "Заказ покупателя"
   - Чтение справочников "Контрагенты" и "Номенклатура"
   - Доступ к HTTP-сервисам
4. Настройте базовую HTTP-аутентификацию

### Шаг 4: Настройка автоматического обновления цен

1. Создайте регламентное задание "Выгрузка цен на сайт"
2. Настройте выполнение каждый час
3. В обработчике:
   - Выберите все товары с актуальными ценами
   - Сформируйте JSON с данными
   - Отправьте POST запрос на сайт: `https://ваш-сайт.ru/api/update-prices.php`
   - Используйте токен авторизации из config.ini

Структура данных для отправки:
```json
{
  "prices": [
    {
      "article": "AVR-100A",
      "price": 45000,
      "available": true
    },
    {
      "article": "AVR-200A", 
      "price": 65000,
      "available": false
    }
  ]
}
```

### Шаг 5: Настройка сетевого доступа

**На сервере 1С:**
1. Откройте командную строку от имени администратора
2. Выполните: `ipconfig` - запишите IPv4-адрес
3. Откройте "Панель управления" → "Система и безопасность" → "Брандмауэр Windows"
4. Создайте правило для входящих подключений на порт 8080
5. Проверьте что 1С запущена и HTTP-сервисы работают

**На роутере офиса (делает системный администратор):**
1. Зайдите в настройки роутера (обычно 192.168.1.1)
2. Найдите раздел "Проброс портов" или "Port Forwarding"
3. Настройте проброс:
   - Внешний порт: 8080
   - Внутренний IP: [IP сервера 1С]
   - Внутренний порт: 8080
4. Узнайте внешний IP офиса на whatismyipaddress.com

### Шаг 6: Проверка работы

**Проверьте HTTP-сервисы:**
1. На сервере 1С откройте браузер
2. Зайдите на `http://localhost:8080/ваша_база/hs/`
3. Должен показать список доступных сервисов
4. Если не работает - проверьте настройки 1С

**Проверьте доступ из интернета:**
1. Зайдите на `http://внешний-IP:8080/ваша_база/hs/`
2. Если не открывается - проблема с сетью/роутером

**Итоговый URL для сайта:**
`http://внешний-IP:8080/ваша_база/hs/orders/create`

### Что передать разработчику сайта

После настройки передайте эти данные:
```
URL 1С: http://ваш-внешний-IP:8080/база/hs/orders/create
Логин: WebService  
Пароль: [пароль который установили]
```

Эти данные нужно будет указать в файле config.ini на сайте.

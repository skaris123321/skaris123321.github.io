# 📧 Настройка приема заказов через Formspree

## Что это?

Formspree - бесплатный сервис для отправки форм на email без своего сервера.
- ✅ Работает из любого браузера
- ✅ Не нужно устанавливать Node.js
- ✅ Бесплатно до 50 заказов в месяц
- ✅ Настройка за 3 минуты

## Инструкция по настройке:

### Шаг 1: Регистрация на Formspree

1. Откройте https://formspree.io/
2. Нажмите "Get Started" (Начать)
3. Зарегистрируйтесь через Google или Email
4. Подтвердите email если нужно

### Шаг 2: Создание формы

1. После входа нажмите "+ New Form" (Новая форма)
2. Введите название: "РОСЭК - Заказы"
3. Укажите вашу почту: **enogovicina167@gmail.com**
4. Нажмите "Create Form" (Создать форму)

### Шаг 3: Получение ID формы

После создания вы увидите страницу с кодом.

Найдите строку похожую на:
```
https://formspree.io/f/xyzabc123
```

Скопируйте последнюю часть после `/f/` - это ваш **Form ID**

Например: `xyzabc123`

### Шаг 4: Вставка ID в код

1. Откройте файл `category/cart.html`
2. Найдите строку (примерно 650):
   ```javascript
   const response = await fetch('https://formspree.io/f/YOUR_FORM_ID', {
   ```
3. Замените `YOUR_FORM_ID` на ваш ID
4. Должно получиться:
   ```javascript
   const response = await fetch('https://formspree.io/f/xyzabc123', {
   ```
5. Сохраните файл

### Шаг 5: Загрузка на GitHub

Запустите `quick-update.bat` чтобы загрузить изменения на сайт.

### Шаг 6: Проверка

1. Откройте ваш сайт
2. Добавьте товар в корзину
3. Оформите тестовый заказ
4. Проверьте почту - должно прийти письмо от Formspree

**Первый раз** Formspree попросит подтвердить отправку - просто нажмите кнопку в письме.

## Как это работает?

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│   Клиент    │         │  Formspree  │         │    Почта    │
│  (браузер)  │────────▶│  (сервис)   │────────▶│    Gmail    │
└─────────────┘         └─────────────┘         └─────────────┘
  Заполняет форму       Обрабатывает           Получаете письмо
  Нажимает "Отправить"  Форматирует            с деталями заказа
```

1. Клиент заполняет форму на сайте
2. Браузер отправляет данные на Formspree
3. Formspree форматирует и отправляет письмо на вашу почту
4. Вы получаете письмо с деталями заказа

## Что будет в письме?

Вы получите письмо с такими данными:
- Тип клиента (физ/юр лицо)
- Контактные данные
- Список товаров с ценами
- Общая сумма заказа
- Комментарий (если есть)

## Преимущества:

✅ Не нужен свой сервер
✅ Работает с любого компьютера
✅ Не нужно ничего устанавливать
✅ Бесплатно для небольших сайтов
✅ Защита от спама встроена

## Ограничения бесплатного плана:

- 50 заказов в месяц
- Письма приходят с пометкой "via Formspree"

Если нужно больше - можно купить платный план ($10/месяц = 1000 заказов)

## Альтернативы:

Если Formspree не подойдет, можно использовать:
- **EmailJS** - 200 писем/месяц бесплатно
- **Web3Forms** - неограниченно бесплатно
- **Telegram Bot** - отправка в Telegram

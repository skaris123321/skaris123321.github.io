# Сайт РОСЭК - PHP версия

Интернет-магазин электротехнического оборудования с интеграцией 1С.

## Быстрый старт

1. Добавьте QR-код оплаты: `images/qr-payment.png`
2. Настройте `config.ini` (токен и данные 1С)
3. Загрузите все файлы на хостинг
4. Готово!

## Требования

- PHP 7.4 или выше
- Модуль PHP cURL (для отправки в 1С)
- Apache с mod_rewrite (или Nginx)

## Структура проекта

```
rosek-site/
├── index.html              # Главная страница
├── config.ini              # Конфигурация (токен, данные 1С)
├── .htaccess               # Настройки Apache
├── category/               # Страницы категорий
├── css/                    # Стили
├── js/                     # JavaScript
├── images/                 # Изображения
├── data/                   # JSON с товарами
├── api/                    # PHP API
│   ├── orders.php          # Прием заказов
│   ├── update-prices.php   # Обновление цен
│   └── health.php          # Проверка работы
└── orders/                 # Сохраненные заказы (создается автоматически)
```

## API Endpoints

- `POST /api/orders.php` - Создание заказа
- `POST /api/update-prices.php` - Обновление цен (требует токен)
- `GET /api/health.php` - Проверка работы сервера

## Как работает

1. Клиент оформляет заказ на сайте
2. Заказ сохраняется в файл `orders/order-YYYY-MM-DD_HH-MM-SS.json`
3. Заказ автоматически отправляется в 1С через HTTP API
4. Клиент видит QR-код для оплаты

## Интеграция с 1С

Подробная инструкция в файле `ИНСТРУКЦИЯ.md`

## Безопасность

- Файл `config.ini` защищен от прямого доступа через .htaccess
- Папка `orders/` недоступна из браузера
- API обновления цен защищен токеном авторизации

ВАРИАНТ 1: АВТОЗАПУСК ПРИ ВКЛЮЧЕНИИ КОМПЬЮТЕРА

1. Нажмите Win + R
2. Введите: shell:startup
3. Нажмите Enter
4. Скопируйте файл autostart-server.bat в открывшуюся папку
5. Перезагрузите компьютер

Теперь сервер будет запускаться автоматически!

───────────────────────────────────────────────────────────

ВАРИАНТ 2: ЗАПУСК ОДНОЙ КНОПКОЙ

Просто дважды кликните на файл:
start-server-with-ngrok.bat

Это запустит:
- Сервер на http://localhost:3000
- Ngrok для доступа из интернета

───────────────────────────────────────────────────────────

ПРОВЕРКА РАБОТЫ:

Откройте в браузере:
http://localhost:3000/api/health

Должно показать:
{"status":"ok","message":"Сервер работает"}

───────────────────────────────────────────────────────────

ОСТАНОВКА СЕРВЕРА:

1. Найдите окно "ROSEK Server"
2. Нажмите Ctrl+C
3. Подтвердите остановку

───────────────────────────────────────────────────────────

ЧТО ДАЛЬШЕ:

1. Настройте автозапуск (Вариант 1)
2. Получите постоянный URL от ngrok
3. Дайте URL программисту 1С
4. Программист настраивает автоотправку из 1С

См. файл: АВТОМАТИЗАЦИЯ-1С.md

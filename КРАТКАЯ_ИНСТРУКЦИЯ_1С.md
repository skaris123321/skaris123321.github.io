# Краткая инструкция для 1С ника

## Что нужно сделать

Создать 3 HTTP-сервиса для интеграции сайта с 1С:

1. **orders/create** - прием заказов
2. **products/list** - отправка товаров
3. **prices/update** - отправка цен

## Быстрый старт

### 1. Создать промежуточные таблицы (если нет)

**WebOrdersImport:**
- OrderID, ClientName, ClientPhone, ClientEmail, OrderTotal, OrderDate, Status

**WebOrderItemsImport:**
- OrderID, Article, ItemName, Quantity, Price

### 2. Создать HTTP-сервис "orders"

URL: `orders/create` (POST)

Получает JSON заказа → пишет в WebOrdersImport и WebOrderItemsImport

### 3. Создать HTTP-сервис "products"

URL: `products/list` (GET)

Читает товары из Номенклатуры → отправляет JSON на сайт

### 4. Создать HTTP-сервис "prices"

URL: `prices/update` (POST)

Читает цены из Номенклатуры → отправляет JSON на сайт

### 5. Создать обработку

Читает новые заказы из WebOrdersImport → создает документ "Заказ покупателя" → обновляет статус

### 6. Создать пользователя WebService

Логин: WebService
Права: создание заказов, чтение товаров

### 7. Настроить сетевой доступ

- Брандмауэр: открыть порт 8080
- Роутер: проброс портов 8080
- Узнать внешний IP

## Формат данных

### Заказ (входящий)

```json
{
  "client": {"name": "...", "phone": "...", "email": "..."},
  "items": [{"article": "...", "name": "...", "quantity": 1, "price": 45000}],
  "total": 45000
}
```

### Товары (исходящий)

```json
{
  "success": true,
  "products": [
    {"article": "AVR-100A", "name": "...", "price": 45000, "stock": 10}
  ]
}
```

### Цены (исходящий)

```json
{
  "success": true,
  "prices": [
    {"article": "AVR-100A", "price": 45000, "available": true}
  ]
}
```

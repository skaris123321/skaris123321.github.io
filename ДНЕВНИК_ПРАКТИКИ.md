## Описание работ, чертежи, схемы, эскизы

В ходе практики выполнена разработка корпоративного сайта ООО «РОСЭК». Ниже приведено описание основных разработанных компонентов.

**Структура сайта:**
- Главная страница (`index.html`) — Hero-секция, бренды, преимущества, слайдер проектов, футер
- Каталог (`category/catalog.html`) — общий список категорий товаров
- Страницы категорий — АВР, шкафы управления, ящики управления двигателями, компенсация реактивной мощности
- Страница товара (`category/product.html`) — галерея, параметры, цена, корзина
- Корзина (`category/cart.html`) — список товаров, форма заказа

**Серверная часть:**
- `api/orders.php` — приём заказов с сайта и передача в 1С
- `api/update-prices.php` — обновление цен из 1С
- `api/health.php` — проверка работоспособности сервера

**Схема взаимодействия компонентов:**
```
Пользователь → Браузер (HTML/CSS/JS)
                    ↓
             api/orders.php (PHP)
                    ↓
             1С:Предприятие (HTTP-сервис)
                    ↓
             Заказ покупателя в 1С
```

**Схема структуры файлов проекта:**
```
rosek-site/
├── index.html          — главная страница
├── css/main.css        — все стили сайта
├── js/                 — JavaScript-модули
├── category/           — страницы каталога
├── data/               — данные о товарах (JSON)
├── api/                — серверные PHP-скрипты
├── images/             — изображения
└── projects/           — фото реализованных проектов
```

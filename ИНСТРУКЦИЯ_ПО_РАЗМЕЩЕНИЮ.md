# Инструкция по размещению сайта РОСЭК на хостинге

## Требования к хостингу

Для работы сайта необходим хостинг с поддержкой:
- Node.js версии 14 или выше
- Возможность запуска Express сервера
- Доступ к файловой системе для записи
- HTTPS (SSL сертификат)
- Минимум 1 ГБ оперативной памяти

Рекомендуемые хостинг-провайдеры:
- Timeweb VPS
- Beget VPS
- REG.RU VPS
- DigitalOcean
- Любой VPS/VDS с Ubuntu/Debian

## Шаг 1: Загрузка файлов на сервер

### Через FTP/SFTP:
1. Подключитесь к серверу через FileZilla или WinSCP
2. Загрузите все файлы проекта в корневую директорию сайта (обычно `/home/username/public_html/` или `/var/www/html/`)

### Через SSH:
```bash
# Подключение к серверу
ssh username@your-server.ru

# Переход в директорию сайта
cd /var/www/html/

# Клонирование из Git (если используется)
git clone https://github.com/your-repo/rosek-site.git .
```

## Шаг 2: Установка зависимостей Node.js

```bash
# Переход в папку сервера
cd server

# Установка зависимостей
npm install
```

Будут установлены:
- express (веб-сервер)
- cors (для кросс-доменных запросов)
- nodemailer (отправка email)
- dotenv (работа с переменными окружения)

## Шаг 3: Настройка переменных окружения

Отредактируйте файл `server/.env`:

```env
# Порт сервера (обычно 3000)
PORT=3000

# Токен для защиты API обновления цен
# ВАЖНО: Замените на свой уникальный токен!
API_TOKEN=ваш-секретный-токен-здесь

# Настройки Gmail для отправки уведомлений о заказах
EMAIL_USER=ваш-email@gmail.com
EMAIL_PASS=пароль-приложения-gmail
ORDER_EMAIL=куда-отправлять-заказы@gmail.com
```

### Как получить пароль приложения Gmail:
1. Перейдите на https://myaccount.google.com/security
2. Включите двухфакторную аутентификацию
3. Перейдите в "Пароли приложений"
4. Создайте новый пароль для "Почта"
5. Скопируйте 16-значный пароль в EMAIL_PASS

## Шаг 4: Настройка автозапуска сервера

### Установка PM2 (менеджер процессов):
```bash
npm install -g pm2
```

### Запуск сервера:

### Настройка автозапуска при перезагрузке:
```bash

pm2 delete rosek-server # Удаление процесса
```

## Шаг 5: Настройка веб-сервера (Nginx)

Создайте конфигурационный файл `/etc/nginx/sites-available/rosek.ru`:

```nginx
server {
    listen 80;
    server_name rosek.ru www.rosek.ru;
    
    # Корневая директория сайта
    root /var/www/html;
    index index.html;
    
    # Статические файлы
    location / {
        try_files $uri $uri/ =404;
    }
    
    # API запросы проксируем на Node.js сервер
    location /api/ {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    # Кэширование статических файлов
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

### Активация конфигурации:
```bash
# Создание символической ссылки
ln -s /etc/nginx/sites-available/rosek.ru /etc/nginx/sites-enabled/

# Проверка конфигурации
nginx -t

# Перезапуск Nginx
systemctl restart nginx
```

## Интеграция с 1С для автоматического обновления цен

### API Endpoint:
```
POST https://rosek.ru/api/products/update-prices
Authorization: Bearer ваш-секретный-токен
Content-Type: application/json

{
  "prices": [
    { "article": "Я5000-0.6-РОСЭК", "price": 15000 },
    { "article": "АВР-25А-2В-CHINT", "price": 45000 }
  ]
}
```

### Пример кода для 1С:

```1c

    JSON = ЗаписьJSON.Закрыть();
    
    // Отправляем HTTP запрос

        "rosek.ru",

        ,

        ,
        30,
        Новый ЗащищенноеСоединениеOpenSSL

    Запрос.Заголовки.Вставить("Content-Type", "application/json");
    Запрос.Заголовки.Вставить("Authorization", "Bearer ваш-секретный-токен");
    Запрос.УстановитьТелоИзСтроки(JSON, КодировкаТекста.UTF8);
```

## Резервное копирование

### Настройка автоматического бэкапа:

Создайте скрипт `/root/backup-rosek.sh`:

```bash
#!/bin/bash

BACKUP_DIR="/root/backups"
DATE=$(date +%Y-%m-%d_%H-%M-%S)
SITE_DIR="/var/www/html"

# Создание папки для бэкапов
mkdir -p $BACKUP_DIR

# Архивация данных
tar -czf $BACKUP_DIR/rosek-data-$DATE.tar.gz \
    $SITE_DIR/data/*.json \
    $SITE_DIR/server/orders/*.json

# Удаление старых бэкапов (старше 30 дней)
find $BACKUP_DIR -name "rosek-data-*.tar.gz" -mtime +30 -delete

echo "Backup completed: rosek-data-$DATE.tar.gz"
```

Добавьте в cron (ежедневно в 3:00):
```bash
crontab -e
# Добавьте строку:
0 3 * * * /root/backup-rosek.sh
```

## Мониторинг

Создайте скрипт `/root/check-rosek.sh`:

```bash
if ! pm2 status rosek-server | grep -q "online"; then
    echo "РОСЭК сервер не работает! Перезапуск..." | mail -s "ALERT: РОСЭК DOWN" admin@rosek.ru
```

```bash
*/5 * * * * /root/check-rosek.sh
```

## Решение проблем

### Сервер не запускается:
```bash
pm2 logs rosek-server --lines 100
```

### Не обновляются цены:
1. Проверьте токен в .env
2. Проверьте права на запись в папку data/
3. Проверьте логи: `pm2 logs rosek-server`

### Не приходят email:
1. Проверьте настройки EMAIL_USER и EMAIL_PASS в .env
2. Проверьте, что включена двухфакторная аутентификация Gmail
3. Проверьте логи сервера

### Сайт не открывается:
1. Проверьте статус Nginx: `systemctl status nginx`
2. Проверьте статус Node.js: `pm2 status`
3. Проверьте логи: `tail -f /var/log/nginx/error.log`

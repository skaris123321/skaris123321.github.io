ШАГ 1: Создать файл prices.json

Формат:
{
  "prices": [
    {"article": "АВР-2-32-М-РОСЭК", "price": 46947},
    {"article": "АВР-2-40-М-РОСЭК", "price": 46947}
  ]
}

───────────────────────────────────────────────────────────

ШАГ 2: Сохранить файл

Сохранить как: prices.json
Кодировка: UTF-8

───────────────────────────────────────────────────────────

ШАГ 3: Отправить администратору сайта

Отправить файл prices.json на email:
enogovicina167@gmail.com

Или через мессенджер

───────────────────────────────────────────────────────────

ШАГ 4: Администратор загрузит цены

Администратор выполнит команду:

cd C:\Users\nogovitsina.ea\Desktop\сайт\rosek-site\server
curl.exe -X POST http://localhost:3000/api/products/update-prices -H "Content-Type: application/json; charset=utf-8" -d "@../prices.json"

───────────────────────────────────────────────────────────

РЕЗУЛЬТАТ:

{"success":true,"message":"Цены обновлены","updated":8}

Цены обновятся на сайте автоматически!

═══════════════════════════════════════════════════════════

ВАЖНО:
- Артикулы должны точно совпадать с сайтом
- Цены в рублях (целые числа)
- Файл должен быть в кодировке UTF-8

# ПОЯСНИТЕЛЬНАЯ ЗАПИСКА К ДИПЛОМНОМУ ПРОЕКТУ

## Тема: Разработка веб-сайта компании по производству электротехнического оборудования

---

# ВВЕДЕНИЕ

## Обоснование выбора темы проекта

Тема дипломного проекта выбрана по предложению руководителя компании ООО «РОСЭК» в ходе прохождения производственной практики. В процессе практики была выявлена актуальная проблема: предприятие производит качественное электротехническое оборудование низкого напряжения, однако основной корпоративный сайт не располагает функционалом онлайн-заказа. Продажи осуществляются преимущественно по телефону и через электронную почту, менеджеры вручную обрабатывают заявки, что приводит к ошибкам и увеличению времени оформления. Клиентам приходится звонить для уточнения цен и наличия товара.

Руководителем предприятия была поставлена задача разработать вспомогательный веб-сайт с каталогом и корзиной, который дополнит основной сайт компании и станет инструментом для удобного оформления заказов. Выполнение данной задачи потребовало проведения анализа требований, проектирования архитектуры, реализации фронтенда и бэкенда, а также тестирования системы. В результате получился готовый программный продукт, который компания может внедрить в производственную деятельность.

## Цели и задачи дипломного проекта

**Цель** — разработать веб-сайт с функционалом интернет-магазина для B2B-сегмента, через который клиенты смогут самостоятельно выбирать оборудование низкого напряжения и оформлять заказы онлайн без участия менеджера.

**Задачи проекта:**

1. Изучить целевую аудиторию и её потребности
2. Проанализировать сайты конкурентов и выявить их недостатки
3. Составить техническое задание с чёткими требованиями
4. Спроектировать структуру хранения данных и архитектуру сайта
5. Разработать главную страницу со слайдером проектов и блоком преимуществ компании
6. Реализовать каталог с четырьмя категориями и фильтрами по характеристикам
7. Создать систему корзины с сохранением в localStorage
8. Реализовать форму оформления заказа для физических и юридических лиц
9. Обеспечить адаптивную вёрстку для мобильных устройств
10. Протестировать функциональность всех модулей

## Актуальность темы

**Цифровизация промышленных предприятий.** Современные компании вынуждены развивать онлайн-каналы продаж для сохранения конкурентоспособности. Потенциальные заказчики сначала ищут поставщиков в интернете, и если сайт отсутствует или не функционален — они переходят к конкурентам.

**Автоматизация бизнес-процессов.** Автоматизация обработки заказов позволяет снизить операционные издержки. Простые заявки, например на покупку двух шкафов АВР, не должны занимать у менеджера время на переписку. Если клиент самостоятельно оформит заказ через сайт, менеджер сможет сосредоточиться на сложных проектах, требующих индивидуального подхода.

**Статистика рынка.** Более 50% B2B-покупок начинаются с онлайн-поиска [1]. Отсутствие функционального сайта или его низкое качество приводит к прямой потере выручки.

На основе выполненного анализа можно утверждать, что разработанный сайт представляет практическую ценность для предприятия и может быть внедрён в производственную деятельность ООО «РОСЭК».

## Обзор аналогов, существующих решений и их недостатков

В рамках аналитической части проведено исследование сайтов основных конкурентов, производящих аналогичное электротехническое оборудование.

**1. Электрощит (elektroschit.ru)** — сайт имеет устаревший дизайн. Каталог присутствует, однако навигация неудобная, фильтры отсутствуют. Цены не указаны — для их уточнения необходимо звонить. Корзина и онлайн-заказ не реализованы.

**2. КЭАЗ (keaz.ru)** — современный дизайн, реализован онлайн-калькулятор подбора оборудования. Вместе с тем цены доступны только после регистрации, форма которой содержит более десяти полей. Корзина отсутствует, предусмотрена лишь форма заявки.

**3. EKF (ekfgroup.com)** — корпоративный сайт высокого качества с личным кабинетом и обучающими материалами. Основной недостаток — низкая скорость загрузки (более пяти секунд) вследствие избыточного использования анимаций.

**4. TDM Electric (tdme.ru)** — простой каталог с ценами, однако возможность онлайн-заказа не предусмотрена. Фильтры и мобильная версия отсутствуют.

**Выявленные общие проблемы:**
- Отсутствие полноценной системы онлайн-корзины у большинства конкурентов
- Низкая производительность сайтов (3–5 секунд загрузки)
- Неадаптивная вёрстка для мобильных устройств
- Необходимость телефонного звонка для уточнения цены
- Ограниченный функционал подбора оборудования по параметрам

## Предполагаемая область применения разработанного продукта

Разработанный сайт предназначен для следующих направлений:

**Основное направление — B2B-продажи:**
- Промышленные предприятия — закупают оборудование для ремонта и модернизации производства
- Строительные и монтажные организации — нуждаются в щитах и АВР для объектов
- Проектные организации — ищут документацию для спецификаций
- Сервисные компании — обслуживают электроустановки

**Дополнительное направление — розничные продажи:**
- Частные лица — оборудование для частных домов и гаражей
- Малые предприниматели — небольшие заказы до 50 000 рублей

Сайт предназначен для пользователей, стремящихся к быстрому подбору оборудования по техническим параметрам и самостоятельному оформлению заказа без длительных переговоров с менеджером.

# РАЗДЕЛ 1. АНАЛИТИЧЕСКАЯ ЧАСТЬ

## 1.1. Обзор предметной области

### Краткое описание проекта

Дипломный проект представляет собой разработку веб-сайта для компании ООО «РОСЭК», специализирующейся на производстве электротехнического оборудования низкого напряжения (до 1 кВ). Сайт решает следующие задачи:

1. **Автоматизация продаж** — клиенты могут самостоятельно оформлять заказы онлайн
2. **Информирование** — подробные характеристики товаров, документация для скачивания
3. **Снижение нагрузки на менеджеров** — простые заказы обрабатываются без участия персонала
4. **Увеличение конверсии** — удобный каталог с фильтрами помогает быстрее найти нужный товар

**Основной ассортимент продукции:**

1. **Автоматический ввод резерва (АВР)** — устройства, переключающие питание на резервный источник при отключении основного. Применяются в больницах, дата-центрах, на производствах — везде, где недопустимо прерывание электроснабжения.

2. **Шкафы управления** — предназначены для управления насосами, вентиляторами, конвейерами. Комплектуются частотными преобразователями или устройствами плавного пуска.

3. **Компенсация реактивной мощности** — установки, снижающие потребление реактивной энергии на предприятиях и уменьшающие нагрузку на электросеть.

4. **Ящики управления Я5000** — устройства для включения и отключения электродвигателей.

### Анализ целевой аудитории

В ходе работы над проектом выделены четыре сегмента клиентов.

**1. Промышленные предприятия (60% продаж)**

Крупные заводы и фабрики. Средний чек — от 100 000 рублей. Оборудование закупается регулярно для ремонта и модернизации производства.

*Ключевые требования к сайту:*
- Быстрый поиск нужного товара
- Открытые цены без регистрации
- Возможность скачать паспорта и схемы
- Получение официальных документов (счёт, договор)

**2. Строительные и монтажные компании (25% продаж)**

Заказы в диапазоне 50 000–200 000 рублей. Оборудование приобретается для монтажа на строительных объектах.

*Ключевые требования:*
- Простое и быстрое оформление заказа
- Оперативная обработка заявки
- Возможность доставки на объект

**3. Проектные организации (10% продаж)**

Инженерные бюро, проектирующие электроснабжение зданий. Закупают редко, однако тщательно выбирают оборудование для спецификаций.

*Ключевые требования:*
- Подробные технические характеристики
- Чертежи и схемы
- Сертификаты соответствия

**4. Частные лица (5% продаж)**

Приобретают оборудование для собственных нужд (частный дом, гараж, мастерская). Заказы до 50 000 рублей.

*Ключевые требования:*
- Понятные цены без скрытых платежей
- Простая процедура оформления

**Портрет типичного пользователя:**
Мужчина 30–55 лет с техническим образованием. Работает инженером, энергетиком или начальником отдела закупок на предприятии. Использует компьютер преимущественно в рабочее время. Ценит скорость работы сайта и однозначность представленной информации.

Это подтверждает необходимость разработки собственного решения с акцентом на скорость работы, простоту использования и функциональность онлайн-заказа.

## 1.3. Техническое задание

### Цели проекта

**Бизнес-цели:**
1. Увеличить количество заказов через сайт на 40% в первый год
2. Разгрузить менеджеров от рутинных заявок
3. Повысить узнаваемость бренда в регионе
4. Увеличить средний чек за счёт удобного подбора товаров

**Технические цели:**
1. Скорость загрузки страниц — не более 2 секунд
2. Доступность сайта — 99,5% рабочего времени
3. Защита персональных данных клиентов в соответствии с 152-ФЗ [2]

### Требования к функционалу

**Главная страница.** Основной вход на сайт. Содержит логотип с навигацией, строку поиска по каталогу, слайдер с примерами выполненных проектов, блок преимуществ компании, раздел с логотипами партнёров и контакты в подвале.

**Каталог товаров.** Четыре основные категории продукции: АВР, шкафы управления, ящики для двигателей, компенсация реактивной мощности. В каждой категории доступны фильтры по характеристикам (бренд, номинальный ток, мощность и другие параметры). Карточки товаров содержат цены, поиск работает по всей базе.

**Карточка товара.** Включает фотографии изделия, полные технические характеристики, цену, кнопку добавления в корзину и ссылки на скачивание документации (паспорта, схемы, сертификаты).

**Корзина заказов.** Позволяет добавлять и удалять товары, изменять количество, отображает итоговую сумму. Данные сохраняются в браузере клиента, поэтому корзина не пропадает при обновлении страницы.

**Оформление заказа.** Клиент выбирает тип заказчика — физическое или юридическое лицо. Для каждого типа отображается соответствующая форма. Данные валидируются перед отправкой на сервер.

### Требования к дизайну

**Цветовая схема.** Основной акцентный цвет — красный (#F16664). Фон светло-серый для снижения нагрузки на глаза. Текст тёмно-серый для обеспечения хорошей читаемости.

**Типографика.** Шрифт Jost от Google Fonts — современный, хорошо читается на всех устройствах, поддерживает кириллицу [3].

**Принципы UI/UX.** Минимализм и практичность в приоритете. Карточки товаров имеют тени и скруглённые углы. Кнопки реагируют на наведение курсора. Анимации сведены к минимуму для обеспечения скорости загрузки.

### Требования к адаптивности

Сайт корректно отображается на трёх типах устройств:
- Десктоп — ширина от 1024 пикселей
- Планшет — от 768 до 1023 пикселей
- Телефон — менее 768 пикселей

На мобильных устройствах используется гамбургер-меню, товары выстраиваются в одну или две колонки. Размер кнопок — не менее 44 пикселей для удобного нажатия пальцем [4].

### Требования к безопасности

1. HTTPS через SSL-сертификат
2. Валидация всех данных на сервере
3. Защита от SQL-инъекций
4. Экранирование пользовательского вывода
5. Соответствие Федеральному закону № 152-ФЗ «О персональных данных» [2]

### Технические ограничения

**Поддерживаемые браузеры:** Chrome, Firefox, Safari, Edge версий 2020 года и новее [5].

**Требования к хостингу:** PHP версии 8 и выше, MySQL версии 5.7 и выше.

**Требования к производительности:** размер главной страницы не более 2 МБ, время загрузки не более 2 секунд, все изображения оптимизированы.

## 1.4. Выбор технологий

### Языки программирования и технологии

**HTML5** — базовая разметка страниц. Современный стандарт, поддерживается всеми актуальными браузерами [6].

**CSS3** — стилизация интерфейса. Реализована собственная система стилей без Bootstrap для минимизации размера файлов.

**JavaScript (ES6+)** — интерактивность: фильтры, корзина, формы. Используется чистый JavaScript без jQuery [7].

**PHP 8** — серверная логика. Выбор обусловлен широкой распространённостью на хостингах, простотой настройки и поддержкой работы с JSON [8].

**JSON-файлы.** Товары хранятся в JSON-файлах для быстрого чтения без необходимости подключения базы данных. Такой подход обеспечивает высокую скорость работы сайта и простоту развёртывания. Структура данных товара представлена в приложении А.

**API для оформления заказа (orders.php).** Серверный скрипт для обработки заказов. Сохраняет данные заказа в файл формата JSON. В коде предусмотрена заглушка для будущей интеграции с 1С — на момент разработки сайт передан компании ООО «РОСЭК» в качестве демонстрационной версии. Примеры API представлены в приложении Б, пример отправки заказа — в приложении Г.

### Библиотеки и фреймворки

**Alpine.js** — лёгкая библиотека для реактивных интерфейсов [9]. Преимущества: подключается одной строкой, не требует компиляции, минимальный размер (~10 КБ), простота использования.

**Google Fonts (Jost)** — шрифт с поддержкой кириллицы, распространяется бесплатно [3].

### Инструменты разработки

- **VS Code** — редактор кода
- **Git** — контроль версий
- **Chrome DevTools** — отладка и тестирование
- **Figma** — проектирование интерфейсов

Структура проекта представлена в приложении В.

### Обоснование выбора технологий

Рассматривались фреймворки React и Vue.js, однако от их применения было решено отказаться по следующим причинам:

1. **Сложность** — требуют настройки системы сборки
2. **Размер** — добавляют более 100 КБ JavaScript, что замедляет загрузку
3. **SEO** — одностраничные приложения хуже индексируются поисковыми системами [10]
4. **Поддержка** — PHP-разработчики более доступны на рынке труда

**Итоговый технологический стек:** HTML5 + CSS3 + JavaScript + Alpine.js + PHP 8 + JSON.

Данный выбор обеспечивает высокую производительность, простоту разработки и поддержки, минимальные требования к хостингу, хорошую SEO-оптимизацию и простоту развёртывания на любом хостинге.

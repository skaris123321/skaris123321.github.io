# Что где находится

## 📁 Основные файлы

### Для работы с сайтом
- `index.html` - Главная страница сайта
- `category/` - Страницы каталога, корзины, товаров
- `css/main.css` - Все стили сайта
- `js/` - JavaScript файлы (корзина, поиск, оплата)
- `data/` - JSON файлы с товарами и ценами
- `images/` - Картинки товаров и баннеры
- `documents/` - PDF файлы (чертежи, сертификаты)

### Для работы с сервером
- `server/server.js` - Основной файл сервера
- `server/.env` - Настройки (порт, email, API банка)
- `server/payments/` - Модуль оплаты через СБП
- `server/payments/history/` - История всех платежей

### Для тестирования
- `test-payment.html` - Страница для тестирования оплаты

### Документация
- `README.md` - Главная инструкция (читать первой!)
- `ДЛЯ-ПРОГРАММИСТА-1С.md` - Инструкция для программиста 1С
- `server/payments/README.md` - Подробная документация модуля оплаты

## 🚀 Что делать дальше

### 1. Запустить сервер локально
```cmd
cd C:\Users\nogovitsina.ea\Desktop\сайт\rosek-site\server
npm install
npm start
```

### 2. Открыть сайт
**Локально:** Открыть `index.html` в браузере
**GitHub Pages:** https://skaris123321.github.io/

### 3. Протестировать оплату
Открыть `test-payment.html` в браузере

### 4. Дать доступ программисту 1С
1. Запустить сервер (см. выше)
2. Запустить ngrok: `ngrok http 3000`
3. Дать программисту URL из ngrok
4. Прочитать `ДЛЯ-ПРОГРАММИСТА-1С.md`

### 5. Загрузить изменения на GitHub
```cmd
cd C:\Users\nogovitsina.ea\Desktop\сайт\rosek-site
git add .
git commit -m "Обновление"
git push
```

⚠️ **ВАЖНО:** 
- GitHub Pages = только frontend (HTML, CSS, JS)
- Backend сервер = нужен для оплаты и обновления цен
- Для работы с 1С нужен запущенный backend!

## ❓ Если что-то не работает

1. Проверьте, что сервер запущен (`cd server && npm start`)
2. Откройте консоль браузера (F12) и посмотрите ошибки
3. Посмотрите логи сервера в терминале
4. Прочитайте `README.md` раздел "Решение проблем"
